# Граф знань для рекомендаційної системи

# Частина 1. Проєктування схеми

## Опис моделі даних

Для роботи використано датасет MovieLens. Дані представлені у вигляді графа, де користувачі оцінюють фільми, а фільми належать до певних жанрів.
Основні сутності:
- User — користувач
- Movie — фільм
- Genre — жанр
Основні зв'язки:
- `(User)-[:RATED]->(Movie)`
- `(Movie)-[:HAS_GENRE]->(Genre)`
Така модель добре підходить для задач рекомендаційних систем, оскільки дозволяє природно представляти взаємодію користувачів із контентом та виконувати складні графові запити.
